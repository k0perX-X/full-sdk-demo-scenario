# Full SDK Demo Scenario

Пример отдельного подпроекта сценария для оркестратора.

Цель:
- показать минимальную структуру внешнего git-репозитория сценария
- продемонстрировать весь актуальный публичный API `orchestrator-sdk`
- дать готовый `algorithm_path` для регистрации сценария в оркестраторе

## Структура

```text
full-sdk-demo-scenario/
├── README.md
├── requirements.lock
├── requirements.txt
└── scenario.py
```

## Как использовать

1. Установить зависимости сценария:

```bash
pip install -r requirements.lock
```

Для локальной разработки внутри монорепозитория можно временно заменить строку в `requirements.txt` на:

```text
-e ../../sdk
```

После этого для локальной разработки можно устанавливать зависимости через:

```bash
pip install -r requirements.txt
```

Файл `requirements.lock` должен оставаться в репозитории сценария и использоваться worker для подготовки зависимостей.

2. Зарегистрировать сценарий в оркестраторе:

- `git_url`:
  URL git-репозитория, в котором лежит этот подпроект
- `version`:
  либо `latest`, либо имя git tag
- `algorithm_path`:
  `scenario.py`

Значение `latest` означает последнюю ревизию ветки, определяемой через `git_url`. Если нужен воспроизводимый запуск конкретной версии, в качестве `version` должно использоваться имя git tag.

3. Выбрать ПО запуска сценария:

- на текущем этапе это одна из доступных в worker версий Python, например `python3.11` или `python3.12`
- сценарий должен быть совместим хотя бы с одной версией Python, доступной в worker

4. Передать во входных данных сценария, например:

```json
{
  "task_description": "hello from scenario",
  "child_prompt": "child hello world",
  "cancel_prompt": "cancel me"
}
```

## Требования к сценарию

- Сценарий должен содержать lock-файл зависимостей, например `requirements.lock`, иначе worker не сможет подготовить воспроизводимое окружение зависимостей.
- Если сценарий должен запускаться в фиксированной версии, в репозитории должен существовать git tag, имя которого используется как значение `version`.
- Сценарий должен быть совместим хотя бы с одной версией Python, доступной в worker.
- Если сценарию требуется конкретная версия Python, это должно быть явно указано в README репозитория сценария.
